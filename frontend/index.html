Zira Platform Terms of Service

01 Atlassian OAuth 2.0 (3LO) Authentication Policy

Zira connects to Atlassian Jira Cloud instances exclusively via 3-Legged OAuth 2.0 (3LO). By granting access, you authorize Zira to execute Jira REST API calls strictly within the permissions granted by your Atlassian account (such as reading work items, creating tickets, and posting comments).

02 Data Encryption & Token Storage

All user credentials, including OAuth access/refresh tokens and Gemini API keys, are stored in encrypted format at rest in PostgreSQL using symmetric Fernet encryption (AES-128 in CBC mode with HMAC verification). Plaintext tokens are never written to disk or exposed in client responses.

03 Responsible AI & API Rate Limits

  • Model Execution: Natural language prompts are processed using Google Gemini AI models.
  • Rate Limiting: Requests are limited to 120 calls per minute per user workspace to ensure system stability.
  • User Oversight: Users retain responsibility for inspecting ticket updates and deletions triggered via agent function calls.

04 Service Availability & Disclaimers

Zira is provided "as is" without warranty. While the platform operates with high availability via Cloudflare Workers and Neon PostgreSQL infrastructure, Zira is not liable for upstream outages affecting Atlassian Cloud or Google AI services.
